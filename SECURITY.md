# Security policy

The active security architecture and control contract is `docs/SECURITY.md`.

Do not open a public issue for a suspected vulnerability. In the private-project phase, report it directly to the repository owner with:

- affected commit/version;
- reproduction steps;
- expected and observed impact;
- any evidence of data exposure;
- suggested containment if known.

No security claim is valid solely because an AI agent or automated scanner reports that a change is safe.
