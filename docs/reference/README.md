# Historical reference material

These files preserve domain evidence and rationale from the original Auto-MB snapshot. They are deliberately outside the active authority chain.

Use them to answer historical or domain questions. Do not restore legacy Factory architecture, roadmap scope, or governance merely because it appears here. Active behaviour must be present in `docs/PRODUCT.md`, `docs/ARCHITECTURE.md`, `docs/SECURITY.md`, or a current ADR.

Reading imported parser comments: a bare `research §N` citation in `packages/loa-parser` means `docs/reference/loa-parser-contract.md §N` (the research document was renamed on import), and `PRODUCT-SPEC` means `docs/reference/legacy-product-spec.md`.

`IMPORT-MANIFEST.json` hashes describe the files **as imported** from the source archive. Comment-provenance rewrites made after import (legacy path citations updated to this repository's layout) mean current file hashes may differ; fixture files and `corpus.json` remain byte-identical and are additionally pinned by the corpus manifest tests.
